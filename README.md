# POCO M5 Audio Emoji (Google Dialer Fart & Sound Reactions)

**POCO M5 (MediaTek Helio G99 / MT6789) — HyperOS Global / MIUI**  
Модуль Magisk + LSPosed для включения эксклюзивной функции Google Pixel **«Звуковые эмодзи»** (Audio Emoji) в приложении «Google Телефон» (`com.google.android.dialer`).

---

## 🔥 Возможности v1.0.4

* 💩 **Настоящие студийные реакции:**
  * 💩 **Пердёж (Fart reaction)** — сочный комедийный звук
  * 👏 **Аплодисменты (Applause)** — ликующий зал и овации
  * 🥁 **Барабанная дробь (Ba-dum-tss)** — классическая сбивка с тарелкой
  * 🎉 **Праздник (Party horn)** — праздничный гудок / фанфары
  * 😢 **Унылый тромбон (Sad trombone)** — вах-вах-вааау
  * 😂 **Смех (Laugh)** — заразительный хохот
* 🔊 **Экстремальная громкость (+30 dB LoudnessEnhancer):** звук прокачивается через встроенный DSP-компрессор `LoudnessEnhancer` с целевым гейном +3000 mB (+30 dB) и направляется одновременно в голосовой апплинк звонка (`USAGE_VOICE_COMMUNICATION` с флагом `FLAG_AUDIBILITY_ENFORCED`) и в динамик телефона (`USAGE_MEDIA`). Звучит оглушительно громко как для собеседника, так и для вас!
* 📱 **Нативный интерфейс прямо в приложении (как на Pixel):** никаких плавающих поверх экрана плашек. Кнопка «Звук. эмодзи» интегрирована прямо в сетку элементов управления экрана разговора Google Телефон.
* 📋 **Фирменная шторка Material 3 Bottom Sheet:** нажатие плавно открывает аутентичную шторку Pixel с карточками звуков, тактильным откликом (Haptic) и салютом взлетающих вверх анимированных эмодзи по всему экрану!
* 🎯 **Безопасный точечный спуфинг:** подменяет `Pixel 8 Pro` исключительно внутри процесса Google Телефон. Камера HyperOS, 90 Гц герцовка экрана и системные настройки POCO M5 остаются нетронутыми!
* 🛡️ **Play Integrity / DenyList Safe:** Сервисы Google Play (`com.google.android.gms`) **НЕ затрагиваются** и остаются в Magisk DenyList / Shamiko. Банки, Mir Pay и верификация устройства не слетают!

## 📦 Установка

1. Скачайте **`MirageAudioEmoji-Magisk-v1.0.4.zip`** (или APK) из раздела [Releases](https://github.com/Mor4land/poco-audio-emoji/releases).
2. Прошейте архив в **Magisk** (или KernelSU / APatch).
3. Перезагрузите устройство.
4. Откройте **LSPosed Manager**, найдите модуль **POCO M5 Audio Emoji** и включите его. Область применения:
   * **Телефон** (`com.google.android.dialer`) — *Сервисы Google Play трогать НЕ нужно, они должны оставаться в DenyList.*
5. Сделайте звонок через Google Телефон — в панели управления звонка появится кнопка **«Звук. эмодзи»**, открывающая шторку реакций!
